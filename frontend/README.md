# Умный кредитный кабинет предпринимателя

Локальный frontend-прототип по кейсу «Альфа Хак». Не официальный сервис банка. Backend, реальная авторизация, скоринг, банковские интеграции и LLM не реализованы.

## Запуск

Откройте эту папку в VS Code. Без установки зависимостей:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Требуется Python 3.10+ только для статического сервера. Не открывайте index.html через file://: ES-модулям нужен HTTP.

Альтернатива: `docker compose up --build`, затем http://localhost:8080. Docker Engine и Compose v2. Образ nginx:1.28.0-alpine зафиксирован в Dockerfile.

Тесты: Node.js 22+ и `npm test`. Пакетных зависимостей нет; lock-файл не требуется. Переменные окружения не используются. Сборка не нужна: dist — исходники и готовый статический сайт.

## Структура

- dist/index.html — оболочка, навигация.
- dist/style.css — адаптивный дизайн и токены.
- dist/app.js — страницы, hash-router, обработчики форм.
- dist/domain.js — чистая функция предварительного расчёта.
- dist/api.js — заменяемый асинхронный адаптер данных.
- docs/BACKEND.md — архитектура, модель, состояния, интеграция.
- docs/openapi.yaml — предлагаемый контракт, согласовать с backend.
- tests/ — проверки расчёта.

## Сценарий проверки

1. Главная: менять сумму, срок и цель — платёж, ставка и переплата меняются. Калькулятор расположен только здесь.
2. Нажать «Подобрать кредит» в калькуляторе или «Войти» в шапке: появляется выбор аккаунта.
3. «Другой» отключён. «Тестовый аккаунт» открывает кабинет.
4. В кабинете нет калькулятора и кнопки входа; кнопка «Войти» скрыта, ниже четыре основных типа кредитов.
5. «Подобрать кредит» открывает модальный диалог с ИИ-заглушкой. Отправить вопрос, проверить демонстрационный ответ.
6. Закрыть диалог крестиком или Escape. Кнопка «Выйти» завершает демосессию и возвращает на главную.
7. Проверить повторное открытие кабинета без демосессии: показывается выбор аккаунта.
8. Проверить экран шириной 390px и навигацию клавиатурой.

Прежняя форма демозаявки сохранена по маршруту #/apply для последующей интеграции; основной сценарий подбора теперь заканчивается диалогом ИИ.

Хранение: localStorage, ключ alfa-demo-applications-v1. Очистка через DevTools → Application → Local Storage. Демосессия хранится в sessionStorage (alfa-demo-session); «Выйти» удаляет её. Это имитация входа, не защищённая авторизация. Не вводите настоящие персональные или банковские данные. При недоступном хранилище форма показывает ошибку.

## Границы MVP

Реализована запрошенная frontend-часть. Полный конвейер из PDF требует backend: проверок, запросов уточнений, решения, ролей банка, документов и аудита. Статусы после отправки показаны как будущие этапы, автоматическое одобрение не имитируется. Нет публикации в GitHub и облаке. Условные ставки 19,5% для оборудования и 21,5% для остальных целей не являются тарифами Альфа-Банка. Аннуитет без комиссий и страхования, округление только при выводе.
